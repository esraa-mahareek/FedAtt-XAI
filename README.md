This repository provides the complete implementation of FedAtt-XAI, a data-decentralized federated learning framework for breast cancer image classification. Each public dataset (BreaKHis, BACH, INbreast, CBIS-DDSM) is formulated as an independent federated task. Clients are simulated with Dirichlet non-IID allocation under patient- or case-level grouping, which prevents leakage between clients and between train, validation, and test partitions. The framework trains an ImageNet-21k-pretrained ViT-Small/16 with layer-wise attention-weighted (FedAtt) aggregation and selects the global checkpoint by federated validation loss. It then personalizes each client, with the adaptation depth conditioned on local data size. Explanations are generated with GradientSHAP using client-local background sets and compared against raw attention, attention rollout, and ViT-Grad-CAM. They are evaluated quantitatively through deletion/insertion faithfulness, stability, localization against expert annotations, and cross-client agreement.

The package also includes six federated baselines (FedAvg, FedProx, FedBN-LN, MOON, FedAS, FedAtt) and a centralized reference trained under an identical protocol. It further contains the component-wise ablations, a Deep Leakage from Gradients stress test, BCa bootstrap effect-size analysis, and scripts that regenerate every table from per-seed outputs. The framework provides data decentralization only; it implements no formal privacy mechanism, and the explanations are not clinically validated.
